Entry for the [make.fun bounty "The Vacuum's Alibi: One Line, 200 Characters"](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7): the funniest one-line excuse a robot vacuum can give for missing a spot.

## The line

> I did not miss the spot. I conducted a thorough survey and concluded the dust has squatter's rights.

## How it works

`main.ts` writes the alibi line to `/output/entry.txt` (100 characters, one line), after checking it against the competition gate: 1–200 characters and bytes, not only whitespace, a single line, and the deadpan denial, the survey, and the punchline phrase all still present.

Run it with Node 22 or later:

```sh
node main.ts
```
